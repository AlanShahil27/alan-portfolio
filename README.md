# Alan Shahil F — HTML Inline CSS Portfolio

This version is a **static HTML project**:
- `index.html` contains the HTML, CSS, and JavaScript.
- No Flask, Python, `requirements.txt`, or separate CSS/JS files are required.
- Profile image and resume are kept in `assets/`.
- The contact form opens the visitor's email app using `mailto:`.
- Ready for static hosting such as Vercel, Netlify, or GitHub Pages.

Open `index.html` directly in a browser to test it.
